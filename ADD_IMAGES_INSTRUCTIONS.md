# How to Add Hollywood Nail Spa Images

## Quick Steps

1. **Download images from Google Images:**
   - Open the Google Images link you provided
   - Right-click on each image you want to use
   - Select "Save image as..."
   - Save them to: `public/images/hollywood-nail-spa/`

2. **Rename images:**
   - Name them: `hollywood-1.jpg`, `hollywood-2.jpg`, etc.
   - Or update the paths in `lib/siteConfig.ts` to match your file names

3. **Image Requirements:**
   - Format: JPG, PNG, or WebP
   - Recommended size: 1200x1200px or larger (square works best)
   - File size: Keep under 500KB per image for fast loading
